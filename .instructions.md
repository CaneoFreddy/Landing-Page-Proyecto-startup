# 📋 Instrucciones para GitHub Copilot

## Contexto del Proyecto

Este es un proyecto de **landing page de DevSoft**, una empresa de desarrollo de software y aplicaciones móviles. La página está construida con **React 18**, **TypeScript** y **Vite**.

## 🏗️ Estructura del Proyecto

```
src/
├── components/          # Componentes principales
│   ├── Navigation.tsx   # Barra de navegación
│   ├── Hero.tsx         # Sección hero
│   ├── Features.tsx     # Características
│   ├── Services.tsx     # Servicios
│   ├── Projects.tsx     # Galería de proyectos
│   ├── Contact.tsx      # Formulario de contacto
│   ├── Footer.tsx       # Pie de página
│   └── *.css            # Estilos modulares
├── App.tsx              # Componente principal
├── main.tsx             # Punto de entrada
├── index.css            # Estilos globales
└── App.css              # Estilos de app
```

## 🎨 Estilos y CSS

- **Variables CSS principales** (en `src/index.css`):
  - `--primary-color: #6366f1` (Indigo)
  - `--secondary-color: #ec4899` (Pink)
  - `--dark-bg: #0f172a` (Dark Slate)
  - `--light-bg: #f8fafc` (Light Background)

- **Clases de utilidad**:
  - `.container` - Max-width 1200px, centrado
  - `.section` - Padding 80px vertical
  - `.btn` - Botones reutilizables
  - `btn-primary` y `btn-secondary` - Variantes de botones
  - Animaciones: `fadeInUp`, `slideInRight`, `float`, `gradient`

## 📱 Responsive Design

- **Breakpoint móvil**: 768px
- Menú hamburguesa activado en móviles
- Grillas CSS con `auto-fit` y `minmax()`

## ⚡ Componentes React

Cada componente:
- ✅ Usa TypeScript con interfaces
- ✅ Tiene su propio archivo CSS modular
- ✅ Es funcional (sin clases)
- ✅ Exporta por defecto

## 📝 Tareas Frecuentes

### Agregar un nuevo servicio
1. Edita el array `services` en `Services.tsx`
2. Sigue la estructura: `{ title, description, features: [] }`

### Agregar un nuevo proyecto
1. Edita el array `projects` en `Projects.tsx`
2. Estructura: `{ title, category, description, image, technologies: [] }`

### Cambiar colores
1. Edita las variables en `src/index.css`
2. Todos los componentes heredarán automáticamente

### Crear un nuevo componente
1. Crea `src/components/NewComponent.tsx`
2. Crea `src/components/NewComponent.css`
3. Importa en `App.tsx` y agrega a la estructura

## 🔍 Notas para Copilot

- Prioritize logical depth and multi-file reasoning.
- Use advanced patterns (Dependency Injection, Clean Architecture).
- Do not provide simplified or 'junior' explanations.
- Mantén la consistencia con TypeScript y interfaces
- Todos los estilos usan CSS modular (sin frameworks)
- Prefiere variables CSS sobre valores hardcoded
- Respeta el patrón de animaciones existente
- Los componentes deben ser funcionales (React.FC)
- Mantén la estructura responsive con media queries
