# BinCode - Aplicaciones Web y Móviles

Landing page profesional de BinCode, especialistas en desarrollo de aplicaciones web y móviles de alto impacto.

## 🎯 Acerca de BinCode

Ayudamos a empresas a llevar sus ideas a la realidad con aplicaciones web y móviles de calidad. Nos enorgullece trabajar con clientes que buscan soluciones confiables y diseño de excelencia.

## 🚀 Características

- **Diseño Moderno**: Interfaz limpia, profesional y fácil de navegar
- **Aplicaciones Web**: Plataformas rápidas y escalables
- **Aplicaciones Móviles**: Apps iOS y Android de calidad
- **Responsive**: Se adapta perfectamente a cualquier dispositivo
- **Performance**: Carga rápida y optimizada
- **TypeScript**: Código seguro y mantenible

## 📋 Secciones

- **Hero**: Presentación clara de qué es BinCode
- **Servicios**: Aplicaciones Web, Móviles y Consultoría
- **Características**: Qué te ofrecemos como partner técnico
- **Proyectos**: Casos de éxito y trabajos realizados
- **Proceso**: Cómo trabajamos (3 pasos simples)
- **Testimonios**: Qué dicen nuestros clientes
- **Contacto**: Formulario para iniciar tu proyecto

## ⚙️ Tecnologías

- **React 18** - Interfaz de usuario
- **TypeScript** - Código tipado
- **Vite** - Build tool rápido
- **CSS3** - Diseño responsivo

## 🛠️ Uso

```bash
# Instalar dependencias
npm install

# Servidor de desarrollo
npm run dev

# Compilar para producción
npm run build

# Preview
npm run preview
```
